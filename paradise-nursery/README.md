# Paradise Nursery

Paradise Nursery is a React and Redux Toolkit shopping-cart application for browsing and purchasing houseplants.

## Features
- Landing page with company details and Get Started button
- 18 unique plants across three categories
- Dynamic Redux shopping cart
- Increase, decrease, and delete cart items
- Dynamic item count and total price
- Responsive navigation and layouts

## Technologies
React, Vite, Redux Toolkit, React Redux, React Router, CSS

## Run locally
```bash
npm install
npm run dev
```
Open the local URL shown by Vite.
